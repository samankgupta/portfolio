# Portfolio Website

This is my personal portfolio website, designed to showcase my projects, experience, and skills with an intuitive and engaging user experience.

## Features

- **Interactive Desktop Layout**: Clean and familiar desktop-style operating interface, providing an organized and modern user experience.
- **Responsive Design**: Optimized for mobile and desktop viewing, ensuring a seamless experience across devices.
- **Interactive Elements**: Includes clickable icons, menus, and smooth transitions between sections.
- **Project Showcase**: Highlights key technical projects with detailed descriptions, technical stacks, and infographic previews.
- **About Me Section**: Personal introduction, resume document viewer, and direct social links (LinkedIn & GitHub).

## Technologies Used

- **Frontend**: React
- **Styling**: Tailwind CSS
- **Deployment**: Vercel / Netlify
